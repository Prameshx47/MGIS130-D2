# Visual Loan Calculator

A single-page web app built for MGIS130 Deliverable 2 demonstrating three-layer architecture with visual cost metrics instead of complex tables.

## Three-Layer Architecture
- **Data Layer:** Captures raw input values from the HTML form into JS objects.
- **Processing Layer:** Runs validation rules, fixed-rate loan formulas, and currency formatting.
- **Presentation Layer:** Displays responsive HTML cards, error messages, and a visual principal-to-interest bar.

## Tech Stack
- HTML5, CSS3 (Grid/Flexbox), Vanilla JavaScript (ES6)
- Hosted on GitHub Pages
